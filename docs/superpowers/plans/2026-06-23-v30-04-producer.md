# V30 Studio Intelligence — Plan 04: Autonomous Operator ("Producer")

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
>
> **Part of the V30 plan series:** 01 → 02 → 03 → **04 (this file)** → 05. **Depends on Plan 01** (`applyBrand`, `state.brand`) **and Plan 03** (`generateCampaign`). Reuses the agent runtime from `ai-cloud.js` but ships as a **separate** surface from the Design Agent.

**Goal:** A "give it a goal, walk away" autopilot. The user picks a preset ("Launch kit", "App Store pack", "Social pack") or types a goal; the Producer plans a bounded sequence of steps, runs them unattended (apply brand → optional redact → generate a campaign), streams a progress log, and surfaces a finished Campaign folder. Pause/Stop supported.

**Architecture:** A new `producer.js` module renders its **own** panel (separate from `ai-agent.js`), reusing that module's chat-log DOM idiom for the progress feed and `runTextPrompt(prompt,{json:true})` to turn a free-text goal into a config. Execution is mostly **deterministic** — it calls the existing programmatic entry points (`applyBrand`, `redact`, `generateCampaign`) in sequence — using the agent runtime only for the goal→config planning step. A module-level abort flag gives Stop. Output is a Campaign folder (Plan 03 storage).

**Tech Stack:** Vanilla JS + Vite. No test runner — verify in `npm run dev` + `npm run build`. Planning via `runTextPrompt` (`claude-sonnet-4-6`/`gpt-4o-mini`). No new persistence (reuses the campaigns store).

## Task 23: Producer planner (goal → step config)

**Files:**

- Produces:

  - `planFromGoal(goal: string) => Promise<ProducerConfig>` — maps a preset name or free-text goal to a config `{ name, applyBrand, redact, includeAppStore, includeTeaser }`. Preset names resolve locally; free text uses one `runTextPrompt` JSON call with a deterministic fallback.

- [ ] **Step 1: Create the module with presets + planner**

Create `src/features/producer.js`:
```js
// v30 — Autonomous Operator ("Producer"). A SEPARATE autopilot surface (not the
// Design Agent): pick a goal, walk away, get a finished Campaign folder. The
// plan is a bounded, deterministic step list; only goal→config planning uses AI.

import { state } from '../state/state.js';
import { runTextPrompt } from './ai-cloud.js';

// A ProducerConfig drives the deterministic executor in Task 24.
export const PRESET_GOALS = {
  'Launch kit':    { name: 'Launch kit',    applyBrand: true,  redact: true,  includeAppStore: true,  includeTeaser: true },
  'App Store pack':{ name: 'App Store pack', applyBrand: true,  redact: false, includeAppStore: true,  includeTeaser: false },
  'Social pack':   { name: 'Social pack',   applyBrand: true,  redact: false, includeAppStore: false, includeTeaser: false }
};

function defaultConfig(name) {
  return { name: name || 'Campaign', applyBrand: !!state.brand?.enabled, redact: false, includeAppStore: true, includeTeaser: false };
}

// Resolve a goal to a config. Presets are exact-match; free text asks the model
// once for booleans, falling back to a sensible default on any failure.
export async function planFromGoal(goal) {
  if (PRESET_GOALS[goal]) return { ...PRESET_GOALS[goal] };
  const g = (goal || '').trim();
  if (!g) return defaultConfig();
  const prompt =
    `You are planning a marketing asset campaign. The user's goal is: "${g}". ` +
    `Return JSON {"name":string,"applyBrand":bool,"redact":bool,"includeAppStore":bool,"includeTeaser":bool} ` +
    `choosing what to include. redact=true only if the goal mentions privacy/PII. ` +
    `includeTeaser=true only if it mentions video/motion/animation.`;
  try {
    const raw = await runTextPrompt(prompt, { json: true });
    const parsed = raw ? JSON.parse(raw) : null;
    if (parsed && typeof parsed === 'object') {
      return {
        name: parsed.name || g.slice(0, 40),
        applyBrand: parsed.applyBrand !== false,
        redact: !!parsed.redact,
        includeAppStore: parsed.includeAppStore !== false,
        includeTeaser: !!parsed.includeTeaser
      };
    }
  } catch (_) { /* fall through */ }
  return defaultConfig(g.slice(0, 40));
}
```

## Task 24: Producer executor (run the plan unattended)

**Files:**
- Modify: `src/features/producer.js` (add the executor + abort flag)

**Interfaces:**
- Consumes: `planFromGoal` (Task 23), `applyBrand` (Plan 01), `redact` (Plan 02), `generateCampaign` (Plan 03), `state`.
- Produces:
  - `runProducer(goal: string, onLog: (line: string) => void) => Promise<{ id }|null>` — plans, then executes the bounded steps, logging each; returns the new campaign id.
  - `stopProducer() => void` — sets the abort flag.

- [ ] **Step 1: Add the executor**

Append to `src/features/producer.js`:
```js
import { applyBrand } from './brand-brain.js';
import { generateCampaign } from './campaign-generator.js';
import { showNotification } from '../ui/notification.js';

let aborted = false;
export function stopProducer() { aborted = true; }

// Execute a bounded plan from a goal, streaming progress to onLog. Each step is
// a known call; the abort flag is checked between steps. Returns { id } of the
// produced campaign, or null on abort/failure.
export async function runProducer(goal, onLog) {
  aborted = false;
  const log = (s) => { try { onLog && onLog(s); } catch (_) {} };

  if (!state.image) { log('✗ Load a screenshot first.'); showNotification('Load a screenshot first.', 'error'); return null; }

  log(`▸ Planning “${goal}”…`);
  const cfg = await planFromGoal(goal);
  if (aborted) { log('■ Stopped.'); return null; }
  log(`✓ Plan: brand=${cfg.applyBrand} redact=${cfg.redact} appStore=${cfg.includeAppStore} teaser=${cfg.includeTeaser}`);

  // Step: apply brand.
  if (cfg.applyBrand) {
    if (state.brand?.enabled) { log('▸ Applying brand system…'); applyBrand(); log('✓ Brand applied.'); }
    else log('• No brand extracted — skipping brand step.');
  }
  if (aborted) { log('■ Stopped.'); return null; }

  // Step: redact PII (no AI key needed for the OCR pass).
  if (cfg.redact) {
    log('▸ Redacting PII…');
    try { const { redact } = await import('./ai-screenshot-editor.js'); await redact({ autoPII: true }); log('✓ Redaction pass done.'); }
    catch (e) { log('• Redaction skipped: ' + (e.message || e)); }
  }
  if (aborted) { log('■ Stopped.'); return null; }

  // Step: generate the campaign (the heavy step).
  log('▸ Generating campaign assets…');
  const res = await generateCampaign({
    name: cfg.name, prompt: '',
    includeAppStore: cfg.includeAppStore, includeTeaser: cfg.includeTeaser
  });
  if (!res) { log('✗ Campaign generation failed.'); return null; }
  log(`✓ Done — campaign “${cfg.name}” is in the Campaigns folder.`);
  return res;
}
```

```js
const $ = (id) => document.getElementById(id);

function logLine(text) {
  const log = $('producer-log');
  if (!log) return;
  const div = document.createElement('div');
  div.className = 'producer-line';
  div.textContent = text;
  log.appendChild(div);
  log.scrollTop = log.scrollHeight;
}

let running = false;

export function bindProducer() {
  $('producer-run')?.addEventListener('click', async () => {
    if (running) return;
    running = true;
    const log = $('producer-log'); if (log) log.innerHTML = '';
    const goal = ($('producer-goal')?.value?.trim()) || ($('producer-preset')?.value) || 'Launch kit';
    try { await runProducer(goal, logLine); }
    finally { running = false; if (typeof window.__refreshCampaigns === 'function') window.__refreshCampaigns(); }
  });
  $('producer-stop')?.addEventListener('click', () => { stopProducer(); logLine('■ Stopping after the current step…'); });
}
```
